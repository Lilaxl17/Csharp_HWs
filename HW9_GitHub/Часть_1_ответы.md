### Дополнительный вопрос

Я бы сделал общий абстрактный класс `Character` с `Name`, `HP` и получением урона. Все персонажи наследуются от него. Для общения использовал бы интерфейс `IInteractable`, а для лечения — `IHealable`.

```text
Character (абстрактный класс, IDamageable)
├── Player — IInteractable, IHealable
├── Enemy
└── NPC — IInteractable
```

Абстрактный класс нужен для общего кода персонажей. Интерфейсы нужны для отдельных умений, которые есть не у всех. Так проще добавлять новые типы персонажей.
