# Домашнее задание Sem9 — JSON и сериализация

Источник: https://github.com/Dark-Andrew-FOX/RYCP-CS-Tasks/blob/main/Sem9/Task.md

## Часть 1

Создать `PlayerSave` с именем, уровнем и монетами; сериализовать в `player.json`, затем десериализовать и вывести значения.

```bash
dotnet run --project Sem9/Part1/Part1.csproj
```

Ожидается вывод `Hero`, уровня `5` и монет `100`.

## Часть 2

Добавить `Inventory` и `HasKey`. При запуске проверять наличие `player.json`, загружать сохранение или создавать персонажа; затем прибавлять 10 монет и сохранять.

```bash
dotnet run --project Sem9/Part2/Part2.csproj
dotnet run --project Sem9/Part2/Part2.csproj
```

На первом запуске, при отсутствии сохранения, будет 110 монет, на следующем — 120. Данные инвентаря и ключа сохраняются между запусками.

В каждом проекте собственный `player.json` сохраняется рядом с исполняемым файлом в `bin/Debug/net8.0/`. Этот файл создаётся автоматически. Для демонстрации повторного запуска **не удаляйте** его между двумя запусками Part2.
